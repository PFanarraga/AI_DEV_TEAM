# Flujo: corregir un error
1. Tester reproduce y documenta.
2. Desarrollador identifica causa raíz.
3. Arquitecto participa si el defecto es estructural.
4. Desarrollador añade corrección y prueba de regresión.
5. Tester vuelve a ejecutar pruebas.
6. Director revisa el diff y comunica limitaciones.
