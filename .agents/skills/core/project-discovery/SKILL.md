# Skill: project-discovery

1. Identifica lenguaje, framework, módulos y puntos de entrada.
2. Lee README, manifiestos, configuración y pruebas.
3. Revisa git status y cambios existentes.
4. Resume arquitectura real; no supongas.
5. Lista dudas y riesgos antes de modificar.
