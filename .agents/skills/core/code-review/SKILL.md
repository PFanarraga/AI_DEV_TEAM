# Skill: code-review

1. Comparar el diff con los criterios de aceptación.
2. Verificar seguridad (OWASP, sanitización de datos, secretos expuestos).
3. Evaluar rendimiento (consultas N+1, fugas de memoria, re-renderizados).
4. Comprobar que existen pruebas automatizadas para los cambios.
