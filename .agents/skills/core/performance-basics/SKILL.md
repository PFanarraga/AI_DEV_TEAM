# Skill: performance-basics

1. Define escenario y métrica.
2. Mide antes de cambiar.
3. Localiza el cuello de botella.
4. Realiza un cambio aislado.
5. Mide de nuevo en condiciones comparables.
6. Conserva el cambio solo si mejora el resultado.
