# Skill: debugging

1. Aislar el error con un caso de prueba o reproducción mínima.
2. Analizar stack traces, logs de servidor y registros de red.
3. Identificar la causa raíz antes de modificar código.
4. Aplicar la solución mínima y verificar que no genera regresiones.
