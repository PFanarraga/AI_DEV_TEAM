# Skill: architecture

1. Analiza la estructura existente.
2. Propón la opción más simple que cumpla requisitos.
3. Define responsabilidades y contratos.
4. Evalúa mantenibilidad, escalabilidad y coste.
5. Documenta decisiones importantes y alternativas descartadas.
