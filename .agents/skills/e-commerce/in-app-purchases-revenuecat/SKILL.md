# In-App Purchases (RevenueCat) Skill

## Propósito
Monetizar aplicaciones móviles con suscripciones, productos consumibles y compras integradas mediante una infraestructura unificada.

## Guía de Implementación

### 1. RevenueCat SDK
- Configurar el SDK de RevenueCat en React Native, Flutter, Swift o Kotlin.
- Validar recibos de compra en el servidor de RevenueCat.
- Manejar restauración de compras (*Restore Purchases*) y pantallas de pago (*Paywalls*).
