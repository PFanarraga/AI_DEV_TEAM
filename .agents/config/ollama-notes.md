# Notas de conexión local
- Servidor Ollama local habitual: http://localhost:11434
- No publiques el puerto en Internet.
- Android Studio puede conectarse mediante Settings > Tools > AI > Model Providers > Local Provider.
- Comprueba el puerto real y el identificador exacto del modelo en tu instalación.
- Selecciona modelos con capacidad de tool calling para Agent Mode.
- Empieza con contexto moderado; aumenta si la memoria lo permite.
- La calidad y funciones disponibles dependen del modelo y de la versión del IDE.
