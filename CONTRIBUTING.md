# Contribuir a AI DEV TEAM

- Mantener documentación en español, salvo nombres técnicos y convenciones.
- Evitar Skills duplicadas; cada nombre debe tener una ubicación canónica.
- Mantener perfiles sincronizados con rutas reales en .agents/skills/.
- No declarar pruebas, builds o capacidades que no se hayan verificado.
- No añadir credenciales, tokens ni datos personales.
- Actualizar README y tutorial cuando cambie el modo de uso.
- Ejecutar python scripts/validate_framework.py antes de integrar cambios.

La especificación de orquestación está en .agents/runtime/ORCHESTRATION.md. Una implementación ejecutable requiere permisos, aprobaciones, límites de costo, cancelación, auditoría y pruebas. No simular delegación autónoma.
