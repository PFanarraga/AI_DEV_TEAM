# Flujo: nueva funcionalidad
1. Director ejecuta project-discovery y planning.
2. Arquitecto define contratos y componentes.
3. UI/UX participa si hay interfaz.
4. Desarrollador implementa por partes.
5. Tester crea/ejecuta pruebas.
6. Seguridad revisa si hay datos, red, autenticación o permisos.
7. Director verifica diff y entrega resumen.
No avances a cambios destructivos o publicación sin aprobación.
