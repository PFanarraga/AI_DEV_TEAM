# Skill: unit-testing

1. Identifica comportamiento público y casos límite.
2. Cubre camino feliz, errores y límites.
3. Usa nombres de prueba descriptivos.
4. Aísla dependencias externas.
5. Ejecuta pruebas y reporta resultados reales.
