# UI/UX Design Skill

## Objetivo
Crear diseños de software profesionales y adaptados al propósito del producto.

## Estilos disponibles

1. Profesional / Premium.
2. Colorido / Creativo.
3. Simple / Minimalista.
4. Detallado / Alta fidelidad.
5. Wireframe / Prototipo.
6. Técnico / Dashboard.

## Reglas de selección

| Tipo de aplicación | Estilo recomendado |
|---|---|
| Bancaria | Profesional |
| Empresarial | Profesional |
| Videojuegos | Colorido |
| Educación infantil | Colorido |
| Herramientas sencillas | Minimalista |
| Aplicaciones comerciales | Alta fidelidad |
| Sistemas administrativos | Dashboard |
| Prototipos iniciales | Wireframe |

Estas recomendaciones no son obligatorias. El usuario puede elegir cualquier estilo.

## Proceso de diseño

1. Comprender el producto.
2. Identificar usuarios.
3. Determinar necesidades.
4. Seleccionar dirección visual.
5. Crear arquitectura de información.
6. Definir sistema visual.
7. Diseñar pantallas.
8. Definir componentes.
9. Diseñar estados e interacciones.
10. Revisar accesibilidad.
11. Entregar especificaciones.

## Sistema visual

Cuando corresponda, establecer:

- Colores.
- Tipografías.
- Tamaños.
- Espaciados.
- Iconos.
- Botones.
- Tarjetas.
- Menús.
- Campos de entrada.
- Estados visuales.
- Animaciones.

## Reglas de calidad

- No utilizar plantillas genéricas sin adaptarlas.
- No repetir diseños automáticamente.
- No sobrecargar interfaces.
- No confundir minimalismo con falta de diseño.
- No confundir colorido con desorden.
- Mantener coherencia entre pantallas.
- Considerar dispositivos de diferentes capacidades.
- Priorizar accesibilidad y facilidad de uso.

## Resultado esperado

Entregar interfaces con calidad profesional, respetando el estilo solicitado y proporcionando información suficiente para su implementación.
