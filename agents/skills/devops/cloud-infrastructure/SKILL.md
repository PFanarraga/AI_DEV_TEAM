# Cloud Infrastructure Skill

## Propósito
Proveer infraestructura en la nube elástica, segura, redundante y de bajo costo.

## Guía de Implementación

### 1. Plataformas Serverless e Infraestructura como Servicio
- **Cloudflare Pages / Workers**: Despliegue estático y funciones edge globales de baja latencia.
- **Supabase**: Base de datos PostgreSQL gestionada, Auth y Storage en la nube.
- **AWS / GCP**: Cómputo con AWS Lambda / GCP Cloud Run o contenedores ECS.

### 2. Infraestructura como Código (IaC)
- Utilizar **Terraform** o **Pulumi** para aprovisionar recursos de nube mediante archivos de código versionados en Git.
