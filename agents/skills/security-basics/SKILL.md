# Skill: security-basics

- Nunca hardcodees secretos.
- Valida entradas en límites de confianza.
- Aplica mínimo privilegio.
- Protege datos sensibles en reposo y tránsito.
- Evita logs con tokens o datos personales.
- Revisa dependencias y permisos.
- Pide aprobación para acciones sensibles.
