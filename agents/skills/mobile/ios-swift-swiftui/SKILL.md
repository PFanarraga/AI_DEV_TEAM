# iOS Native (Swift & SwiftUI) Skill

## Propósito
Desarrollar aplicaciones iOS nativas elegantes, eficientes y seguras integrando las últimas tecnologías del ecosistema de Apple.

## Guía de Implementación

### 1. Interfaz de Usuario con SwiftUI
- Usar vistas compuestas, `@Observable` (Swift 5.9+) y modifiers limpios.
- Garantizar soporte para modo oscuro, Dynamic Type (fuentes adaptables) y accesibilidad (VoiceOver).

### 2. Concurrencia Moderna
- Usar `async/await`, `Task` y `Actors` para concurrencia segura sin data races.

### 3. Persistencia
- Utilizar **SwiftData** o **CoreData** para bases de datos locales encriptadas.
