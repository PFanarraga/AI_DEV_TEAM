# UI Accessibility Skill

## Objetivo
Garantizar que las interfaces sean fáciles de utilizar para diferentes personas y dispositivos.

## Revisiones obligatorias

### Contraste
- Revisar contraste entre texto y fondo.
- Comprobar legibilidad de iconos.
- No depender exclusivamente del color para transmitir información.

### Navegación
- Navegación intuitiva.
- Orden lógico de elementos.
- Estados de foco visibles.
- Etiquetas comprensibles.

### Adaptabilidad
- Diferentes tamaños de pantalla.
- Orientación vertical y horizontal.
- Escalado de texto.
- Diferentes resoluciones.

### Interacciones
- Botones suficientemente grandes.
- Mensajes claros.
- Confirmaciones.
- Errores comprensibles.
- Estados de carga.
- Estados vacíos.

### Rendimiento
- Animaciones ligeras.
- Evitar efectos innecesarios.
- Optimizar recursos gráficos.
- Considerar dispositivos de gama baja y media.

## Informe final

Indicar:
1. Problemas detectados.
2. Nivel de gravedad.
3. Elementos afectados.
4. Soluciones recomendadas.
5. Resultado de la revisión.
