# Skill: release-checklist

- Requisitos y cambios revisados.
- Pruebas relevantes ejecutadas.
- Build reproducible.
- Secretos y configuración revisados.
- Permisos y dependencias revisados.
- Notas de versión actualizadas.
- Copia de seguridad y aprobación antes de publicar.
