# Skill: coding-standards

- Sigue el estilo del repositorio.
- Usa nombres descriptivos y funciones pequeñas.
- Evita duplicación y abstracciones innecesarias.
- Maneja errores explícitamente.
- Comenta el porqué, no lo obvio.
- No añadas dependencias sin justificar.
