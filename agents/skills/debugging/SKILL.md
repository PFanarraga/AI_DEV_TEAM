# Skill: debugging

1. Obtén el mensaje completo y contexto.
2. Reproduce el fallo con pasos mínimos.
3. Formula hipótesis y compruébalas una a una.
4. Identifica causa raíz, no solo síntoma.
5. Corrige y añade una prueba de regresión.
6. Informa qué no se pudo verificar.
